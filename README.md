# teslainvite.com

Static referral page in several languages, generated from one template.

## Structure
| File | What it is |
|---|---|
| `locales/<lang>.json` | All text for each language, plus the Tesla country code (`teslaLocale`). **Edit here.** |
| `build.js` | Generates `index.html` (English, default) and `no/`, `sv/`, `da/`, `de/`, `fr/`, `es/`, `it/`, `nl/`, plus `sitemap.xml`. |
| `main.js` | Click tracking (GA), copy button, language switcher memory, language banner. |
| `main.css` | Styling. |

The generated HTML files are committed, so Cloudflare Pages needs no build step.
**Never edit `index.html` or the language folders directly.** They are overwritten on the next build.

## Edit text
1. Change `locales/<lang>.json`
2. `node build.js` (or `npm run build`)
3. Commit and push

If you change `eyebrow` or `h1`, also update the share images: `node build.js --og` (needs Google Chrome).

## Add a language
1. Copy `locales/en.json` to e.g. `locales/pl.json` and translate it. Set `lang`, `hreflang`, `path` (`/pl/`), `ogLocale`, `teslaLocale` (`pl_pl`) and `browserLangs`.
2. Add the code to `LANG_ORDER` in `build.js`.
3. `node build.js --og`

`hreflang`, sitemap, language switcher, redirect and language banner update automatically.

## The "About me" section
Hidden as long as `"about": null`. Fill it in per language, e.g.:

```json
"about": {
  "heading": "Hvem er jeg?",
  "image": "/img/meg.jpg",
  "imageAlt": "Dan med sin Tesla Model Y",
  "paragraphs": [
    "Jeg heter Dan og har kjørt Tesla Model Y siden 20XX. …",
    "Lurer du på noe før du bestiller? Send meg gjerne en e-post på <a href=\"mailto:…\">…</a>."
  ]
}
```

## Language
- English at `/` is the default and `x-default`.
- `/` sends visitors to their browser language's page (inline script in `<head>`, generated by `build.js`). It does **not** redirect if the visitor picked a language before (`localStorage`), or came from another page on the site.
- Language pages (`/no/`, `/de/` …) never redirect. If the browser language has another page, a small banner suggests it.
- The English page uses a Tesla link without a country (`tesla.com/referral/…`). Tesla chooses the region.

## Run locally
`python3 -m http.server 8765` and open http://localhost:8765/

## Deploy
Push to `main`. Cloudflare Pages publishes automatically.
